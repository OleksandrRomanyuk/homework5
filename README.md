
# Пробний сайт  

## Мета проєкту
Створення навчального вебсайту для проходження тестів з різних предметів. Сайт допомагає користувачам перевіряти свої знання та закріплювати вивчений матеріал з української мови, математики та історії України.

## Використані технології
- HTML — структура та вміст вебсторінок.
- CSS — оформлення, стилізація та адаптація елементів інтерфейсу.
- Git — контроль версій проєкту.
- GitHub — зберігання вихідного коду та спільна робота.
- GitHub Pages — публікація сайту в інтернеті.

## Перевірка результату
У результаті виконання роботи сайт було успішно додано до Git-репозиторію та завантажено на GitHub. Було налаштовано файл .gitignore, створено документацію README, виконано роботу з окремою гілкою та об'єднано зміни через Pull Request.
Після публікації на GitHub Pages перевірено відкриття головної сторінки та коректне відображення її вмісту, оформлення CSS та доступність тестів з усіх представлених предметів.
